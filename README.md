# Deepfake Audio Detection System

A machine learning-based security system designed to detect synthetic speech (voice clones) and classify audio recordings as either **Genuine (Human)** or **Deepfake (AI-Generated)**.

## Project Overview

With the rapid advancement of generative artificial intelligence, creating highly realistic voice clones (deepfakes) has become trivial. While this enables innovative applications, it also introduces substantial risks—including financial fraud (voice phishing), disinformation campaigns, and vulnerabilities in voice biometric security systems. 

This project delivers an end-to-end machine learning pipeline that extracts temporal and spectral acoustic features from audio samples and uses an optimized LightGBM classifier to detect synthetic speech. The system is deployed as an interactive Streamlit web application, enabling users to upload audio files and analyze them in real-time.

---

## Problem Statement

Traditional speech verification systems assume that voice input is produced by a live human. However, modern text-to-speech (TTS) and voice conversion (VC) technologies can synthesize speech that is virtually indistinguishable to the human ear. 

The goal of this project is to build a robust, generalizable classifier capable of distinguishing between:
1.  **Genuine Speech**: Authentic human voice recordings.
2.  **Deepfake Speech**: Synthesized or converted voices generated using various AI vocoders and neural speech synthesis systems.

---

## Features

-   **High-Accuracy Detection**: Out-of-the-box detection of voice clones and synthetic speech.
-   **137 Acoustic Features**: Leverages detailed spectral, temporal, and harmonic features.
-   **Multi-Format Support**: Upload `.wav`, `.mp3`, `.ogg`, `.flac`, or `.m4a` files.
-   **Audio Player**: Listen to uploaded clips directly within the interface.
-   **Visual Analytics**: Real-time generation of audio waveforms and log-frequency spectrograms.
-   **Confidence Metrics**: Displays probability scores for both Genuine and Deepfake classifications.
-   **Low-Confidence Warning**: Flags noisy or highly compressed files that fall outside the training distribution.

## Dataset Description

The model was trained and evaluated on two major speech benchmarks:

1.  **The Fake-or-Real (FOR) Dataset**: 
    -   A large-scale dataset containing over 100,000 speech utterances.
    -   Features both authentic human speech and synthetic speech generated by modern voice synthesis architectures.
    -   Includes various subsets: original, normalized (`for-norm`), 2-second clips (`for-2seconds`), and re-recorded utterances (`for-rerecorded`) to test robustness against environment noise.
2.  **ASVspoof 2019 Logical Access (LA) Dataset**:
    -   The industry-standard evaluation benchmark for speech spoofing.
    -   Contains speech generated via 17 different text-to-speech (TTS) and voice conversion (VC) algorithms, helping ensure the model generalizes well to unseen cloning tools.

## Model Architecture & Acoustic Features

The system extracts **137 acoustic features** from each audio signal using the `librosa` library. The features capture distinct aspects of human vs. synthetic speech patterns:

| Acoustic Feature Category | Dimensions | Description |
| :--- | :---: | :--- |
| **Mel-Frequency Cepstral Coefficients (MFCCs)** | 40 | Represents the envelope of the short-term power spectrum (timbre). |
| **Delta MFCCs** | 40 | First-order temporal derivatives capturing dynamic spectral changes. |
| **Delta-Delta MFCCs** | 40 | Second-order temporal derivatives capturing speech acceleration. |
| **Chroma STFT** | 12 | Measures the energy distribution across the 12 semitone pitch classes. |
| **Spectral Centroid** | 1 | Represents the "center of gravity" of the spectrum (brightness). |
| **Spectral Bandwidth** | 1 | Measures the width/spread of the spectral distribution. |
| **Spectral Rolloff** | 1 | The frequency below which 85% of the spectral energy resides. |
| **Zero Crossing Rate (ZCR)** | 1 | Rate of sign-changes in the raw audio waveform (high in noise/sibilants). |
| **Root Mean Square (RMS) Energy** | 1 | Quantifies the signal power and loudness profile over time. |

### Classifier
An **Augmented Generalized LightGBM** classifier was selected for deployment. LightGBM (Light Gradient Boosting Machine) is a tree-based gradient boosting framework that offers:
-   Extremely fast training and inference speeds.
-   Low memory footprint.
-   Excellent handling of tabular acoustic feature vectors.
-   Robustness against overfitting when trained on augmented feature sets.

## Training Process

The model training pipeline is documented in the [Deepfake_Audio_Detection.ipynb](file:///c:/Users/ACER/.antigravity-ide/antigravity-skills/deepfake_project/Deepfake_Audio_Detection.ipynb) Jupyter notebook:

1.  **Preprocessing**: Audio inputs are resampled to a uniform rate of 16kHz, converted to mono channel, and normalized to ensure volume consistency. Silent sections are trimmed using a decibel threshold.
2.  **Padding & Truncating**: Short clips (under 2048 samples) are padded to a minimum duration to avoid dimension mismatches during feature extraction.
3.  **Feature Extraction**: Librosa computes the 137 features. The mean across time frames is calculated for each feature type, producing a single 137-dimensional vector per audio file.
4.  **Data Split**: The dataset is divided into training, validation, and test splits (matching the standard splits defined in FOR and ASVspoof).
5.  **Model Training**: LightGBM is trained on the extracted features, optimizing binary log-loss. Hyperparameter tuning is conducted using cross-validation.
6.  **Serialization**: The final model is serialized and saved as `deepfake_audio_detector_lgbm_augmented_generalized.pkl` using `joblib`.

The LightGBM model achieves state-of-the-art efficiency and competitive accuracy on independent test sets:

## Installation

Ensure you have Python 3.9+ installed. Follow these steps to set up the project locally:

1.  **Clone the Repository**:
    ```bash
    git clone https://github.com/BinaryBardX/Deepfake-Audio-Detection.git
    cd Deepfake-Audio-Detection
    ```

2.  **Create a Virtual Environment**:
    ```bash
    python -m venv venv
    # Activate on Windows:
    venv\Scripts\activate
    # Activate on macOS/Linux:
    source venv/bin/activate
    ```

3.  **Install Dependencies**:
    ```bash
    pip install -r requirements.txt
    ```

## Usage

### Running the Streamlit Web App

To launch the web interface locally, run:

```bash
streamlit run app.py
```

Open `http://localhost:8501` in your browser.

1.  **Upload an Audio File**: Drag and drop any supported format (e.g., `.wav`, `.mp3`).
2.  **Review the Output**: The app will instantly display whether the audio is **GENUINE** or a **DEEPFAKE**, alongside the model's confidence probability.
3.  **Explore Visualizations**: Interact with the dynamically generated **Waveform** and **Spectrogram** plots showing the frequency patterns of the uploaded audio.
